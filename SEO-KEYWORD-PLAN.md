## Conditional nearby-area terms

Public local search listings use nearby locality names such as **Patratu, Bhadaninagar, Ramgarh Cantt, Patel Nagar, and Bhurkunda Bazar**. These are conditional phrase examples, not a recommendation to claim that HM Motors serves all these localities. Use a nearby-area phrase only after the owner confirms HM Motors actually serves that area and the site gives useful, truthful information for those customers. Do not create thin doorway pages by changing only the locality name. Confirm directory data because it can be stale or incomplete.

## Terms to publish only when true

“New”, “second-hand”, “for sale”, “service”, “repair”, “test ride”, “finance”, “exchange”, brand/model names, prices, availability, “certified”, “warranty”, “best”, and “authorized dealer” claims must match the current real offering and be verifiable. The site’s enquiry form, EMI estimate and test-ride request must not be described as confirmed finance, a loan approval, a confirmed ride, or a guaranteed exchange valuation.

Do not target another business’s brand/company name or suggest affiliation. The goal is accurate visibility for HM Motors’ own local showroom and actual listings, not misleading comparisons or keyword stuffing.

## Implemented in the website

The source now provides locality-aware headings; distinct page titles, descriptions and compact keyword hints; category-specific landing pages; actual vehicle/model/condition detail metadata; canonical URLs; Open Graph/Twitter sharing tags; conditional AutoDealer structured data only when canonical origin, address and phone are configured; and a sitemap limited to the main indexable pages plus published vehicle pages. It excludes private admin/API URLs from crawl paths. Google may ignore HTML `meta keywords`; the useful visible content and actual inventory are more important.

## Free Render subdomain checklist

In Owner Controls → Website settings, set **Public website HTTPS URL** to `https://hm-motors.onrender.com` exactly (no `/admin`, trailing path, or query). Check:

- `https://hm-motors.onrender.com/robots.txt`
- `https://hm-motors.onrender.com/sitemap.xml`

Add the HTTPS URL-prefix property in Google Search Console, submit `/sitemap.xml`, then inspect the homepage and category pages. A free Render subdomain can be used; a paid custom domain is not required for these steps. Google controls crawl timing, indexing and positions, so no SEO change can guarantee ranking or outrank another company.
